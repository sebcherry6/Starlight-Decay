# Starlight Decay

A rework of my college Asteroids game in C# and MonoGame: ten sectors, ten bosses, enemies, collectibles and upgrades.

## Run it

Needs the .NET 8 SDK or newer. From the `Starlight Decay/Starlight Decay` folder:

    dotnet tool restore
    dotnet run

Or open `Starlight Decay.sln` in Visual Studio and press F5.

## Controls

| Key | Action |
| --- | --- |
| W or Up | Thrust |
| A D or Left Right | Turn |
| S or Down | Brake |
| Space | Fire |
| Shift | Dash |
| E or Q | Bomb |
| Esc | Pause |
| M | Mute |
| F11 | Fullscreen |
| F9 | Debug builds only: skip to this sector's boss |

## Where things are

| To change | Look in |
| --- | --- |
| Sectors, waves and hazards | `Levels/LevelData.cs` |
| Boss health and attack patterns | `Bosses/BossData.cs` |
| Upgrade prices and ship stats | `Core/RunState.cs` |
| Enemy behaviour | `Enemies/Enemy.cs` |
| Wave flow and collisions | `World.cs` |

Sprites and new sounds were generated by the scripts in `tools/`, which need Python with NumPy and Pillow. You only need those to regenerate the art or audio.

New images and sounds must be added to `Content/Content.mgcb`, and to the name lists in `Core/Assets.cs` or `Core/Sfx.cs`.
